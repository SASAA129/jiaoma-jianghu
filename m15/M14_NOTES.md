## 唯一改动：满掌柜头上的当前目标「！」圆章 / 金底名牌不再压住招牌「椒麻鸡火锅」

- `js/markers.js`：
  - 配置对象新增 `signText: { shop: [...] }`（按场景登记字区，以后别的场景有字可照加）、`signPad: 6`（含目标牌上下浮动 4px）。
  - 每帧把字区换成屏幕 px；名牌（含「！」）按原规则放好后，若与字区相交，就按候选位置依次试：满掌柜身侧右（头顶高度）→ 身侧左 → 身侧右 / 左（肩部高度）→ 脚下 → 整体移到字区下方 → 字区右侧 → 字区左侧。
    每个候选同样避开 HUD，取第一个不压字、不压别的名牌 / 别人身子、不压他自己身体的位置；都不满足时取压得最少的那个。
  - 改挂后仍是金底 `.npc.target` + 红「！」，紧挨满掌柜的头 / 肩，一看就是他的；点击照旧走过去交互。
  - 规则对所有名牌都生效（物件牌、贴边牌也不压字）；屏外贴边指路逻辑不变。
  - `Markers.list()` 多返回 `moved:"sign"`，另有 `Markers.signRects()`，供测试用。
