# 跑酷火锅店 v0

竖屏三车道跑酷小游戏原型（色块 + emoji，无生图）。

规格：`/workspace/game-design/paoku/SPEC_v0.md`

## 怎么玩

- **左右滑**或**点左/右半屏**换车道（键盘 ← → / A D 也行）
- 接到 🥬菜 +10、🧧红包 +50
- 撞到 😱催账 -2 体力；🍲汤 / 🪑板凳 -1
- 连续 5 次接到不撞 → 下一次得分 ×1.5
- 体力 3 格扣光出局；撑到 90 秒强制结算
- 星级：200 / 400 / 700 分

## 本地怎么开

```bash
cd /workspace/game-paoku-v0
python3 -m http.server 8100
```

浏览器打开：http://127.0.0.1:8100/

手机建议竖屏全屏访问。
